# WorkflowEditor 测试项目 (React 18.3.1)

这是一个用于测试 `@lucksoft/aiflow-editor` 工作流编辑器组件的项目，基于 React 18.3.1。

## 运行项目

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev
```

## 项目功能

1. 展示 WorkflowEditor 组件
2. 提供获取流程图数据的按钮
3. 展示获取的流程数据

## 技术栈

- React 18.3.1
- Vite
- Ant Design v5
- @lucksoft/aiflow-editor@0.1.0
